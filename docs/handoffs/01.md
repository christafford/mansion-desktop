## Next task

Complete the minimal nested compositor implementation.

## Prerequisites

Set up the development environment following [DEVELOPMENT.md](../DEVELOPMET.md) or use the Docker container.

## Detailed requirements

1. Implement EGL rendering (display.cpp):
   - Load EGL function pointers
   - Choose EGL config
   - Create EGL context
   - Create EGL surface for host window (using X11 platform)
   - Set up GLES2 rendering

2. Implement surface commit handling (compositor.cpp):
   - Track surface state (pending and current)
   - Handle `wl_surface::commit`
   - Set up buffer and renderer integration
   - Handle surface deletion

3. Implement input handling (input.cpp):
   - Create seat global
   - Implement `wl_keyboard`:
    - Create keyboard objects
    - Send key events to focused surface
    - Send mod器器ifier events
    - Send focus enter/leave
   - Implement `wl_pointer`:
    - Create pointer objects
    - Send motion events
    - Send button events
    - Send axis events
   - Track focus and coordinate transformation

4. Implement rendering (display.cpp):
   - Create a simple GLES2 renderer
   - Render surfaces as textured quads
   - Render solid color for backgrounds
   - Swap buffers

5. Implement launcher (launch.cpp):
   - Set `WAYLAND_DISPLAY` environment variable
   - Set `XDG_RUNTIME_DIR` to a temp directory
   - Fork and exec child process
   - Track running clients
   - Handle child exit

6. Implement shell surface operations (shell.cpp):
   - `ping` - respond to pings
   - `move` - implement interactive move
   - `resize` - implement interactive resize
   - `fullscreen` - implement fullscreen
   - `maximize - implement maximize
   - `minimize` - implement minimize
   - `set_window_type` - implement
   - `set_title` - implement
   - `set_class` - implement

7. Verify:
   - Terminal starts and displays
   - Typing works
   - Resizing works
   - Closing the terminal exits cleanly
   - Host desktop remains usable after Mansion Desktop exits

## Implementation notes

- Use the Wayland C API (header `<wayland-server.h>`)
- Use EGL for OpenGL rendering
- Use xkbcommon for keyboard handling
- Implement proper error handling and cleanup
- Start with 2D rendering - no 3D yet
