# Project 2: perspective panel — handoff

Living document for Project 2. Updated in P2-T03.

## Context

P2 adds a 3D perspective panel: a camera views a panel plane onto which the
compositor projects a client surface as an OpenGL texture. Supports
`--flat` (2D path) and `--camera X,Y,Z,YAW,PITCH` for 3D mode.

## Known issues / blockers

- **P1-T10 (human):** Requires `sudo pacman -S weston` and host DISPLAY session.
- **Orphaned surface gap in `render_panel` (fixed in P2-T03):** When a client
  disconnects, the surface is moved to `orphaned_surfaces`. Fixed by:
  (1) clearing `focused_surface_resource` in `surface_destroy_callback`, and
  (2) adding a fallback search of `orphaned_surfaces` in `render_panel()`.
- **Mesa EGL swizzle bug:** Surfaceless renderer stores GL_RGBA data internally
  as `[B,R,G,A]` (cyclic shift). Compensation: `rgba[idx+0]=data[idx+1](R),
  rgba[idx+1]=data[idx+2](G), rgba[idx+2]=data[idx+0](B), rgba[idx+3]=data[idx+3](A)`.
